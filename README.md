## Task 1 - Digital Literacy Awareness Infographic
<br/><br>
Module 1:
<br/><br>
A single page came together here, built to help students grasp what digital literacy means. This idea took shape by breaking down complex thoughts into clear pieces, showing why these skills matter in school and jobs. A visual rhythm guided the flow, shaped through tools like Canva, Prezi, or Miro. Color met structure on that surface, turning abstract ideas into something you could see and follow.
What you see breaks down core ideas - like what digital literacy really means, useful tech tools for learners, how to browse safely online, plus ways to keep an image that looks serious on the web. Visuals such as symbols, brief explanations, and clear zones guide your eye, helping thoughts stick without clutter weighing them down.
This time around, communication got sharper because of how ideas took shape visually. Shaping the message meant sorting pieces carefully, yet keeping things fresh. A tight space pushed choices - only key bits stayed, even when pressure built to include more. Clarity had to win, so visuals lined up evenly, each element holding its ground. Picking what truly mattered? That part tested patience more than expected.
